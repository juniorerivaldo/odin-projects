# odin-projects Raylib + Odin - 50 Desafios de Jogos Incrementais
Um repositório de aprendizado progressivo para desenvolvimento de jogos usando Raylib e Odin. Este projeto contém 50 desafios cuidadosamente organizados para levar você de conceitos básicos a sistemas complexos de jogos.
📋 Sobre o Projeto
Este repositório é uma jornada de aprendizado estruturada em 5 níveis de dificuldade crescente. Cada desafio foi projetado para construir sobre os conceitos anteriores, permitindo que você desenvolva habilidades sólidas de programação de jogos de forma gradual e consistente.
Por que Raylib + Odin?

Raylib: Biblioteca de jogos simples e direta, perfeita para aprendizado
Odin: Linguagem moderna, rápida e com sintaxe clara

🎮 Estrutura dos Desafios
🟢 Nível 1: Jogos Básicos de Movimento (1-10)

1. Quadrado Controlável

Objetivo: Criar um quadrado que responde às teclas direcionais
Conceitos: Input básico, renderização de formas, loop de jogo
Dificuldade: ⭐

2. Círculo Seguidor

Objetivo: Fazer um círculo seguir suavemente a posição do mouse
Conceitos: Input do mouse, interpolação de movimento, coordenadas
Dificuldade: ⭐

3. Pulo Simples

Objetivo: Implementar pulo com física de gravidade ao pressionar espaço
Conceitos: Física básica, velocidade vertical, aceleração
Dificuldade: ⭐⭐

4. Ricochete nas Bordas

Objetivo: Sprite que inverte direção ao tocar os limites da tela
Conceitos: Detecção de bordas, inversão de vetores
Dificuldade: ⭐

5. Aceleração Gradual

Objetivo: Movimento que acelera e desacelera suavemente (não instantâneo)
Conceitos: Interpolação linear, easing, delta time
Dificuldade: ⭐⭐

6. Rotação em Movimento

Objetivo: Objeto que gira enquanto se desloca pela tela
Conceitos: Transformações, ângulos, rotação de sprites
Dificuldade: ⭐

7. Animação de Caminhada

Objetivo: Personagem com sprite sheet que anima ao se mover
Conceitos: Sprite sheets, frame timing, animação por frames
Dificuldade: ⭐⭐

8. Movimento 8 Direções

Objetivo: Controle direcional completo com velocidade normalizada
Conceitos: Vetores 2D, normalização, movimento diagonal
Dificuldade: ⭐⭐

9. Dash/Teleporte

Objetivo: Movimento rápido instantâneo em uma direção ao pressionar tecla
Conceitos: Cooldowns, impulso de velocidade, trail effects (opcional)
Dificuldade: ⭐⭐

10. Plataforma Móvel

Objetivo: Plataforma que se move e carrega o jogador junto

```
## 💡 Dicas de Desenvolvimento

### Para Cada Desafio:

✅ **Faça funcionar primeiro** - Não se preocupe com código perfeito
✅ **Adicione estados de jogo** - Menu, gameplay, game over, restart
✅ **Reutilize código** - Crie uma biblioteca pessoal de funções úteis
✅ **Use formas geométricas** - Não perca tempo com arte no início
✅ **Foque no "game feel"** - Faça cada mecânica ser satisfatória de jogar
✅ **Comente seu código** - Você voltará a ele depois
✅ **Faça commits frequentes** - Documente sua jornada

### Organização de Código Sugerida:
```
desafio-XX/
├── main.odin          # Loop principal do jogo
├── game.odin          # Lógica do jogo
├── entities.odin      # Jogador, inimigos, etc.
├── utils.odin         # Funções auxiliares reutilizáveis
├── README.md          # Descrição e reflexões sobre o desafio
└── assets/            # Sprites, sons (se houver)
